# Financial Analysis Dashboard (Power BI)

# Overview

Developed an interactive Power BI dashboard to analyze financial performance and track key business metrics.

# Tools Used

* Power BI (DAX, Power Query)
* Excel

# Key Features

* KPI tracking (Revenue, Profit, Expenses)
* Interactive filters and slicers
* Trend analysis and performance insights

# Dataset

* Financial dataset (Excel-based)

# Insights

* Identified revenue growth trends
* Highlighted cost patterns affecting profitability
